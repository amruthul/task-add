# Dynamic To-Do App

A sleek, dark-themed task management web application designed to help you stay organized and focused. 

## Tech Stack

* **Backend:** Python
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Dependencies:** Managed via `requirements.txt`

## Features

* **Add Tasks:** Quickly add items using the intuitive input field.
* **Mark as Complete:** Toggle checkboxes to cross out finished tasks with a clean strike-through effect.
* **Delete Tasks:** Remove unwanted items from your list using the delete icon.
* **Modern UI:** Distraction-free, visually appealing dark mode design.
